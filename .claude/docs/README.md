# Agent docs

This directory holds working documentation for agents (and Jon) about this repo, the
jonkonrath.com site. It's where context lives that doesn't belong in the code or in the
root CLAUDE.md: why things were done, how larger features work, gotchas, and anything
Jon has asked to have written down.

## Rules

- **Read before you work.** Agents must read this README and any docs relevant to their
  task before starting work. The root CLAUDE.md points here.
- **Write after you change things.** Small changes get noted in the root CLAUDE.md.
  Larger features, or anything Jon asks to have documented, get their own Markdown file
  here.
- **Keep it current.** If a doc is wrong or stale, fix it. Don't add a new doc that
  contradicts an old one.

## Conventions

- One topic per file, Markdown, lowercase kebab-case names.
- Start each doc with a short summary and the date it was written or last updated
  (YYYY-MM-DD).
- Add every new doc to the index below with a one-line description.
